# Marp

### Créer des présentations avec Markdown

**Simple • Rapide • Moderne**

---

# 1. Qu'est-ce que Marp ?

Marp est un outil qui permet de créer des **présentations** en utilisant **Markdown**.

- Simple à utiliser
- Basé sur Markdown
- Transforme le texte en slides
- Permet de créer des présentations en HTML ou PDF

---

# 2. Pourquoi utiliser Marp ?

Marp permet de créer des présentations de manière :

-  **Rapide**
-  **Simple**
-  **Personnalisable**
-  **Accessible aux développeurs**

On écrit le contenu en Markdown au lieu de créer chaque slide manuellement.

---

# 3. Comment fonctionne Marp ?

Marp utilise des éléments Markdown pour créer les slides.

```markdown
# Mon titre

Ceci est mon contenu.

---

# Deuxième slide

- Exemple 1
- Exemple 2
```

Le symbole `---` permet de **séparer les slides**.

---

# 4. Exemple avec Marp

```markdown
---
marp: true
---

# Ma présentation

## Introduction

- HTML
- CSS
- JavaScript

---

# Conclusion

Markdown + Marp = Présentation simple
```

Marp transforme automatiquement ce contenu en **slides**.

---

# 5. Conclusion

### Marp + Markdown

**Marp** est une solution simple pour créer des présentations avec du **Markdown**.

- Facile à apprendre
- Rapide à utiliser
- Adapté aux développeurs
- Export possible en **PDF, HTML et PPTX**
